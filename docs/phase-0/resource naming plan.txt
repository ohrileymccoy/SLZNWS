# Resource & Binding Plan — Oak Hill News (Phase 0)

This document records the exact names/labels we will use when provisioning Cloudflare resources and wiring Pages Functions. Keep this in Git as the source of truth.

## Environments (MVP)
- [x] prod
- [ ] staging (later)
- [ ] dev (later)

## Cloudflare Resources

### D1 (SQL database)
- **D1 database name:** `ohn_prod`
- **Pages Functions binding:** `DB`
- **Notes:** Read-only at MVP; drafts never returned by public endpoints.

### R2 (object storage for media)
- **R2 bucket name:** `ohn-media`
- **Pages Functions binding:** `MEDIA`
- **Public read at MVP:** Yes (simple keys)
- **Notes:** Signed URLs can be introduced later for uploads/admin.

### KV (edge key-value store)
- **KV namespace name:** `ohn-cache`
- **Pages Functions binding:** `CACHE`
- **Use cases:** Short-lived response cache, simple counters, soft rate-limit flags.
